FAQ Rental PlayStation

Apa saja syarat sewa konsol bawa pulang?

Cukup melampirkan foto E-KTP asli, bersedia diverifikasi alamat domisili, dan deposit jaminan (atau KTP asli ditinggal selama durasi penyewaan).

Apakah bisa booking tempat bermain (On-Site) terlebih dahulu?

Sangat disarankan booking online agar tidak kehabisan unit PS5/PS4 di jam sibuk (malam/akhir pekan).

Bagaimana jika controller rusak saat disewa?

Kerusakan minor atau pemakaian normal tidak dikenakan denda. Denda hanya berlaku jika terjadi benturan keras, terkena cairan, atau kelalaian disengaja.

Developer & Architecture Guide

Dokumentasi Backend & Skema Database

Panduan lengkap migrasi dari Web Frontend Demo ke Backend Produksi (Node.js/Express + PostgreSQL/MySQL + Payment Gateway).

Skema Tabel PostgreSQL (Migration SQL) 

CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    whatsapp VARCHAR(20) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    role VARCHAR(10) DEFAULT 'user',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE consoles (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    generation VARCHAR(10) NOT NULL, -- PS1, PS2, PS3, PS4, PS5
    price_per_hour INT NOT NULL,
    status VARCHAR(20) DEFAULT 'Tersedia',
    image_url TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE bookings (
    id SERIAL PRIMARY KEY,
    booking_code VARCHAR(20) UNIQUE NOT NULL,
    user_id INT REFERENCES users(id),
    console_id INT REFERENCES consoles(id),
    start_time TIMESTAMP NOT NULL,
    duration_hours INT NOT NULL,
    total_price INT NOT NULL,
    payment_status VARCHAR(30) DEFAULT 'Menunggu Konfirmasi',
    whatsapp_notified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Endpoint API RESTful

GET /api/v1/consoles Mendapatkan seluruh daftar konsol & status ketersediaan.
POST /api/v1/bookings Membuat pesanan sewa baru (Validasi bentrok jam otomatis).
PUT /api/v1/admin/bookings/:id/status Update status sewa & pembayaran oleh Admin.
POST /api/v1/payments/webhook Webhook verifikasi callback Midtrans / Xendit.
Catatan Keamanan Backend: Password harus di-hash menggunakan bcrypt minimal 10 salt rounds. Kunci API Midtrans/Xendit dan kredensial database WAJIB disimpan di file .env terisolasi di server.
